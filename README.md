# Montash Studio

Десктоп-программа для нарезки длинного видео на короткие клипы с автоматическими
караоке-субтитрами (Shorts / TikTok / Reels).

## Возможности

1. **Авто-субтитры под звук** — распознавание речи (faster-whisper) с таймингом каждого слова.
2. **Количество клипов и хронометраж** — выбираются ползунками; клипы ищутся там,
   где больше всего речи, и начинаются с начала фразы.
3. **Формат** — 9:16 (Shorts / TikTok / Reels), 1:1, 16:9; заполнение кадра:
   обрезка по центру, размытый фон или чёрные полосы.
4. **Видеоэффекты** — цветокоррекция (кино, тёплый, холодный, Ч/Б, сочный), виньетка.
5. **Редактор субтитров** — правка текста фраз, шрифт, цвет подсвеченного слова
   (которое звучит в данный момент), основной цвет текста, цвет и толщина обводки,
   размер, позиция, кол-во слов на экране, ЗАГЛАВНЫЕ, анимация «прыжок».
6. **Живое превью** кадра с субтитрами в любой момент клипа.

### Вкладка «Фильм → клип»

Вставляете текст про фильм и добавляете файлы фильма (можно несколькими частями) —
программа сама собирает **один клип** нужной длины (по умолчанию 1 минута):

- **Под текст (по сюжету)** — фразы раскладываются по фильму в хронологическом порядке,
  для каждой берётся самый динамичный план на своём участке;
- **Интересные моменты** — самые динамичные места всего фильма (движение, частые склейки,
  громкий звук), в порядке сюжета;
- субтитры делаются из вашего текста с подсветкой текущего слова;
- **звук и музыка фильма отключаются**; можно добавить свою озвучку (тогда длина клипа =
  длине озвучки, а субтитры привязываются к речи) и фоновую музыку;
- чёрные кадры, вступление и финальные титры пропускаются;
- любой план можно заменить кнопкой 🔄 или вписать таймкод вручную;
- «Обновить только субтитры» — поправить текст, не меняя подобранные кадры.

Анализ фильма делается один раз и кэшируется (`~/.montash_cache`).

#### ИИ-подбор сцен (необязательно)

Режим **«ИИ: сцены по смыслу текста (Claude)»**: из каждого плана фильма берётся ключевой
кадр, Claude коротко описывает кадры (кто в кадре, что делает, где), а затем подбирает
под каждую фразу кадры, которые показывают именно то, о чём в ней говорится.
Кнопка 🔄 сначала перебирает другие варианты ИИ, затем — обычный подбор.

- Нужен интернет и ключ API Anthropic (console.anthropic.com) — вводится в разделе
  «ИИ-подбор сцен» или через переменную `ANTHROPIC_API_KEY`.
- Ключевые кадры фильма (512 px) отправляются в Claude API.
- Стоимость: первый анализ фильма ≈ $0.3–0.5 на Claude Opus 5.5 (примерно вдвое меньше
  на Sonnet 5.5); описания кадров кэшируются, поэтому повторные сборки с новым текстом
  стоят центы. Примерная сумма показывается после сборки.

## Запуск из исходников

```bash
pip install -r requirements.txt
python main.py                 # графический интерфейс
python main.py video.mp4 -n 5 -d 30 --lang ru -o clips   # консольный режим
python main.py film --text script.txt part1.mkv part2.mkv -d 60 -o clip.mp4
python main.py film --text script.txt film.mkv --mode ai --ai-key sk-ant-... -o clip.mp4
```

Нужен ffmpeg: он берётся из папки программы, из `PATH` или из пакета `imageio-ffmpeg`.
При первом распознавании модель Whisper скачивается автоматически
(`small` ≈ 500 МБ; `tiny`/`base` — быстрее, `medium`/`large-v3` — точнее).

## Сборка .exe (Windows)

```bat
build_exe.bat
```

Результат — `dist\Montash\Montash.exe`. Шрифты для субтитров можно положить в папку
`fonts` рядом с exe (например, Montserrat Black, Bebas Neue).
