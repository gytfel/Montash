# Montash Studio

Десктоп-программа для нарезки длинного видео на короткие клипы с автоматическими
караоке-субтитрами (Shorts / TikTok / Reels).

## Возможности

1. **Авто-субтитры под звук** — распознавание речи (faster-whisper) с таймингом каждого слова.
2. **Количество клипов и хронометраж** — выбираются ползунками; клипы ищутся там,
   где больше всего речи, и начинаются с начала фразы.
3. **Формат** — 9:16 (Shorts / TikTok / Reels), 1:1, 16:9; заполнение кадра:
   обрезка по центру, размытый фон или чёрные полосы.
4. **Видеоэффекты** — цветокоррекция (кино, тёплый, холодный, Ч/Б, сочный), виньетка.
5. **Редактор субтитров** — правка текста фраз, шрифт, цвет подсвеченного слова
   (которое звучит в данный момент), основной цвет текста, цвет и толщина обводки,
   размер, позиция, кол-во слов на экране, ЗАГЛАВНЫЕ, анимация «прыжок».
6. **Живое превью** кадра с субтитрами в любой момент клипа.

## Запуск из исходников

```bash
pip install -r requirements.txt
python main.py                 # графический интерфейс
python main.py video.mp4 -n 5 -d 30 --lang ru -o clips   # консольный режим
```

Нужен ffmpeg: он берётся из папки программы, из `PATH` или из пакета `imageio-ffmpeg`.
При первом распознавании модель Whisper скачивается автоматически
(`small` ≈ 500 МБ; `tiny`/`base` — быстрее, `medium`/`large-v3` — точнее).

## Сборка .exe (Windows)

```bat
build_exe.bat
```

Результат — `dist\Montash\Montash.exe`. Шрифты для субтитров можно положить в папку
`fonts` рядом с exe (например, Montserrat Black, Bebas Neue).
